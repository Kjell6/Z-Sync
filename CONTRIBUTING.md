# Contributing

Thanks for taking an interest in Z-Sync.

**Feature requests** — open an issue (use the Feature request form), so it can be discussed before anyone writes a PR. If it gets a go, PRs are welcome. The change needs to land on iOS and Android together.

**Bugs** — no issue needed first. If you know what is broken and how to fix it, send the PR. Open an issue instead when you cannot fix it yourself, or when the fix is large or changes behaviour.
